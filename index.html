Day 2 Laser Parameter Chart (SIL Lab) ▼

// Concept: Speed, Power & Mode by Material

Studied the SIL lab's laser parameter reference chart — the cheat sheet used when setting Layer Parameters in LaserCAD.

  • Acrylic CUT: 2 mm → speed 22–24, power 45–50; 18 mm → speed 1–2, power 90–95
  • Acrylic Engrave: SCAN mode, speed 280–300, power 12–20

  • Wood tip: Increase power, keep speed below 25
  • Chiller must be started before the machine; water changed every 15 days

Day 4 Control Systems — P, PI & PID ▼

// Concept: Feedback Control Theory

Learned about control systems used in automation and robotics to regulate speed, temperature, and position.

  • P Controller: Output proportional to error — fast but may have steady-state error
  • PI Controller: Adds Integral term → removes accumulated error; more accurate, slightly slower
  • PID Controller: P (present) + I (past) + D (future) — highest accuracy, fastest stable response; used in robots, drones, industrial systems

Day 1 ESP32 Complete Documentation ▼

// Chip: Espressif ESP32 · Concept: SoC Architecture & Pinout

Deep dive into the ESP32 ecosystem — the chip that powers most projects in the lab.

  • ESP32: Dual-core 240 MHz, Wi-Fi + BT 4.2, successor to ESP8266 (2016)
  • GPIO: 34 programmable pins; ADC1 (8 ch, Wi-Fi safe), ADC2 (10 ch, no Wi-Fi), DAC on GPIO25 & 26
  • Communication: 3× UART, 4× SPI, 2× I2C, 2× I2S, CAN 2.0, Ethernet MAC
  • Pinout: GPIO6–11 = internal flash (avoid!), GPIO34–39 = input-only, GPIO0/2 = strapping pins
  • Frameworks: Arduino IDE (easiest), ESP-IDF (official C/C++), MicroPython, PlatformIO
  • Variants: S2 (USB), S3 (BT5, AI), C3/C6 (RISC-V), H2 (Zigbee/Thread)
ESP32SoCPinoutGPIOWi-Fi
Day 2 Arduino Uno, Nano & Mega 2560 ▼

// Boards: ATmega328P / ATmega2560 · Concept: Board Selection

Compared three classic Arduino boards to understand which to use in different project scenarios.

  • Uno Rev3: ATmega328P @ 16 MHz, 14 digital I/O (6 PWM), 6 analog — ideal for beginners, fits shields
  • Nano: Same ATmega328, smallest footprint, 8 analog inputs (A0–A7), plugs into breadboard — for space-limited builds
  • Mega 2560: ATmega2560 @ 16 MHz, 54 digital I/O, 16 analog, 4× UART, 8 KB SRAM — choose when pin count matters
  • All run 5V logic, use Arduino IDE, and accept the same sketch syntax

Day 4 BO Motors, L298 Driver & MG995 Servo ▼

// Components: L298 H-Bridge, MG995 Servo · Concept: Motor Control

Learned how DC motors and servos work, and how to control them with an H-bridge driver.

  • BO Motor Gearbox: Multiple spur gear stages reduce RPM → multiply torque; yellow plastic housing + white compound gears
  • Motor internals: Rotor coil, commutator, permanent magnets (stator), brushes, noise capacitor
  • L298 H-Bridge: PWM varies voltage → controls speed; current reversal → changes direction (CW/CCW); one module controls 2 motors
  • MG995 Servo: ~120° rotation, metal gears, 3-wire connector (brown/red/orange), standard servo library compatible
  • Closed-loop servo control: Controller → Drive signal → Motor → Encoder → Feedback
BO MotorL298MG995PWMH-Bridge

// Tool: Edge Impulse Studio · Concept: ML on Microcontrollers

Trained a machine learning model to classify images of letters A, B, and C — deployed targeting Cortex-M4F microcontroller.

  • Created project: Alphabets_classification, target: Cortex-M4F 80 MHz
